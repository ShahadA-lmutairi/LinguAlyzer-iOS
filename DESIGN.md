# Design notes

## Colors

| Name | Hex | Use |
|---|---|---|
| Forest | `#0D594D` | Primary buttons, accents |
| Mint | `#DBF0E6` | Secondary buttons, highlights |
| Canvas | `#F6F8F5` | Screen background |
| Ink | `#142630` | Main text |
| Muted | `#647575` | Secondary text |
| Line | `#E0E8E0` | Card borders |

## Type

System font (SF), rounded for the title and score. Arabic text is set right-to-left with its own alignment.

## App icon

Two speech bubbles: the back one (mint) holds a Latin **A**, the front one (white) holds the Arabic letter **ع**. A check badge sits at the top right. It stands for a translation that was reviewed.

## Principles

- The tool suggests, the reviewer decides.
- Say plainly what the score does and does not mean.
- Keep text on the device.
